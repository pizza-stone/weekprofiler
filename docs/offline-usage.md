# 离线版使用与云端迁移

## 下载后双击使用

1. 下载 **[weekprofiler-preview.html](https://github.com/pizza-stone/weekprofiler/releases/latest/download/weekprofiler-preview.html)**，或在 [Release 页面](https://github.com/pizza-stone/weekprofiler/releases/latest)的 Assets 中下载同名文件。
2. 将 HTML 文件放在固定位置，双击并用浏览器打开。
3. 从「任务」整理清单，在「模板」建立大纲，再到「一周」安排时间。点击计划上的 `▶` 开始计时，在「计划＋执行」中回看实际投入。

**使用离线核心功能无需安装 Node.js、启动服务器、联网或注册 Google 账号。首次打开也可以离线。** 程序、样式和图标都包含在这个 HTML 文件中。

下载文件需要联网。当前仓库为私有，下载者需要 GitHub 仓库访问权限；拿到文件后，离线使用无需登录 GitHub 或 Google。

AI 排程是可选的测试性功能，需要额外的本机服务、登录和联网条件；上述离线说明适用于任务、模板、排程、计时与统计。可以完全不使用 AI，具体配置见 [README 的 AI 说明](../README.md#ai)。

## 数据保存、备份与升级

日程保存在浏览器的本地存储中，**不会写回 HTML 文件**。因此：

- 建议一直使用同一个浏览器、同一个文件位置。更换浏览器、移动或重命名文件后，不保证能读到原来的本机记录。
- 定期通过「导出与备份」保存完整 JSON 备份。清理浏览器网站数据可能删除本机记录；HTML 文件本身不能替代数据备份。
- 换电脑时，复制 HTML 作为程序，再通过「设置 → 从 JSON 备份恢复」导入自己的数据。
- 更新离线版前，先导出 JSON 备份，再下载新版 HTML。打开新版后核对内容，必要时恢复备份；确认无误前保留原文件与备份。

恢复 JSON 会替换目标入口的当前内容，请先备份目标数据，并核对恢复预览。ICS 只适合导入日历，不是周谱的完整迁移备份。

## 迁移到云同步版

**可以保留离线版中的任务、模板、日程与执行记录，迁移后在电脑和手机之间同步。** 需要先部署云同步服务，再导入数据；单独上传或打开离线 HTML 不会自动开启同步。

1. 在离线页面通过「导出与备份」导出完整 JSON，保留这份原始备份。
2. 按[个人云同步部署指南](cloudflare-setup.md)创建自己的 Cloudflare Worker 与 D1，并配置 Google 登录。已有 Google 账号即可配置，不需要为周谱另外新建一个；登录邮箱必须是部署时允许的邮箱。
3. 联网打开自己的云端网址并登录。如果云端已有数据，先导出一份云端备份。
4. 在云端页面的「设置 → 从 JSON 备份恢复」选择离线备份，核对预览后确认。**这一步会替换云端当前内容。**
5. 等待显示已同步，再用手机打开同一网址、使用同一账号登录，核对任务与执行记录。其他设备会读取云端内容，无需各自再导入一次。

迁移后使用云端网址作为日常入口。原离线 HTML 仍是独立的本机数据副本，之后在其中所做的修改不会自动传到云端。

Google 只验证身份；日程存放在自己的 Cloudflare D1 中，不会因为 Google 登录而存入 Google Drive。云同步版首次登录和同步需要联网；成功加载、登录并缓存后可离线编辑，重新联网打开页面后补同步。断网重新打开页面还依赖缓存未被清理。
