### 云同步测试的范围

云同步截图使用仓库的 Cloudflare Worker 构建产物与真实同步接口，在只监听本机的 `cloud-preview.mjs` 中运行。测试身份和 SQLite 数据库由预览服务提供，均与个人线上实例隔离。

本次在 `127.0.0.1` 与 `localhost` 两个独立浏览器来源之间验证了：第一端开始计时，第二端读取同一个计时器并结束，第一端刷新后读取到结束状态。截图中的“已同步”表示与这个独立测试数据库同步成功。

这些图片展示同步版界面与本机双端行为，**不是生产 Cloudflare 部署、Google 登录或手机真机验证的截图**。正式环境的部署与验证步骤见[云同步部署指南](cloudflare-setup.md)。

## 体验演示周表

[demo-week-lived-in.json](demo-week-lived-in.json) 用于首图和桌面与手机布局对比图。在基础周表上调整了执行起止时间，并加入分段投入与临时任务，模拟使用一周后的状态。两种布局连接同一个独立 `cloud-preview.mjs` 测试数据库；手机宽度由浏览器模拟，不代表手机真机测试。

[demo-week.json](demo-week.json) 是其余 5 张截图使用的基础备份，包含：

- 2026-11-16 至 2026-11-22 的虚构一周；
- 4 个项目分组、5 个标签、16 个任务；
- 5 个日模板、2 个周模板和启用的周循环；
- 周一至周四的 23 段虚构执行记录，计时器初始状态为停止。

基础备份把工作、学习、创作、生活和休息组合在同一周中。周四的具体计划共 420 分钟，示例执行共 320 分钟，已覆盖 305 分钟，因此时长覆盖率为约 72.6%。首图变体采用不同执行记录，统计数值也会相应变化。

计时截图是在这份基础数据上另外开始一次“阅读与笔记”演示计时所得；该临时演示已结束，不包含在下载的基础备份中。

在独立的周谱浏览器入口中打开「设置 → 从 JSON 备份恢复」，选择示例文件、查看预览后确认。再用日期选择器跳到上述日期即可查看完整周表。**导入会替换目标入口当前的数据**，请先备份已有内容，或在没有个人日程的新浏览器配置中体验。

重新截图时，可以通过 `node portable.mjs` 生成本机版，或通过 `node build.mjs`、`node cloud-preview.mjs` 启动本机同步测试。向独立演示入口导入对应备份即可，不需要使用个人线上日程。
